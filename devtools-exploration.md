# DevTools Exploration

## Website 1: https://example.com
1. **HTML Tags Used:** `<html>`, `<head>`, `<title>`, `<meta>`, `<style>`, `<body>`, `<div>`, `<h1>`, `<p>`, `<a>`
2. **Page Title:** Example Domain
3. **Number of Headings:** 1 (one `<h1>`)

## Website 2: https://developer.mozilla.org
1. **Navigation Tag:** `<nav>`
2. **Search Bar Structure:** It is contained inside a `<form>` element with `role="search"`. Inside, there is an `<input>` element with `type="search"` (or `type="text"`) where you type your query, along with a search `<button>`.
3. **Hover Effect:** The link text changes color (for example, switching to a brighter blue or underline), and the CSS `cursor` property changes to `pointer` (the hand icon).

## Website 3: https://www.lamborghini.com/en-en
1. **5 HTML Elements:** `<header>`, `<nav>`, `<section>`, `<picture>` (or `<img>`), `<footer>`
2. **Form Elements & Inputs:**
   - **Form:** Search Form (`<form>` inside the header modal or overlay search panel).
   - **Inputs:** `<input type="search">` (or `<input type="text">`) for typing queries, and `<button type="submit">` (or `<button type="button">`) to execute the search.
